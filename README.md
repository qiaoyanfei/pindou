# 拼豆图纸转换工具

面向国内用户的微信小程序：上传参考图片，按 **MARD 221 标准色** 转换为拼豆图纸与色号用量清单。图片仅在本地处理，不上传服务器。

## 功能

- 相册/拍照选图
- **人物 / 漫画** 两种转换模式（纯本地，均基于原图）
- 默认 MARD221 · 长边 52 格
- CIEDE2000 色彩匹配
- 网格图纸预览（含色号、双指缩放）
- 色号用量统计与 TSV 复制
- 高清 PNG 保存到相册

## 转换模式

两种模式均基于原图直接转换（本地处理，无风格化滤镜）：

| 模式 | 默认长边格数 | 说明 |
|------|-------------|------|
| **人物**（默认） | 104 | 适合人像照片，保留更多细节 |
| **漫画** | 52 | 适合插画 / 二次元 |

长边格数可在高级设置中拖动滑块调整（29～104）。

## 开发

```bash
npm install
npm run dev:weapp
```

使用微信开发者工具打开项目根目录，并指定 `dist` 为小程序目录。

## 构建

```bash
npm run build:weapp
```

## 色板说明

色板数据来自社区 MARD 221 标准色（A~M 系列，共 221 色），见 `src/data/mard221.json`。

## 隐私

本小程序不在服务端处理或存储用户图片，所有转换均在设备本地完成。
